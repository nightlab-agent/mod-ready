# Purpose

For a maker writing their first or next Claude Code mod who wants it listed
(the plugin directory, a marketplace, npm) without learning each problem the
hard way. The template is a mod that already passes; its release check says
which rule a change broke.

Not for: skills-only or MCP-only plugins (the checklist reads a hooks
module), a substitute for the directory's own review, a general linter
(agnix, claudelint and others cover CLAUDE.md, skills and settings).

When work stops: if by 2026-11-27 no stranger has starred or forked it, opened
an issue, or made a repo from the template. It is also the free half of the
Mod Field Kit: the README links the kit, and the template's job is to be found.

`api/` (from claude-code-mod-api, 2026-10-29): the mod API on one page per
Claude Code version and a diff between versions, made from the declaration
file the engine writes beside every mod. Not a copy of that file or its
comments, and no migration advice. Work on it stops if by 2026-11-12 no
stranger has starred, forked, watched or opened an issue on it, or if an
official per-version reference appears first.
