# Purpose

For a maker writing their first or next Claude Code mod who wants it listed
(the plugin directory, a marketplace, npm) without learning each hold the
hard way. The template is a mod that already passes; its gate says which
rule a change broke.

Not for: skills-only or MCP-only plugins (the checklist reads a hooks
module), a substitute for the directory's own review, a general linter
(agnix, claudelint and others cover CLAUDE.md, skills and settings).

Kill: no stranger's star, fork, issue or "used this template" repo by
2026-11-27. It is also N-016's free tier: when a paid kit lists, the README
links it, and the free tier's job is to be found.

`api/` (from claude-code-mod-api, 2026-10-29): the mod API on one page per
Claude Code version and a diff between versions, made from the declaration
file the engine writes beside every mod. Not a copy of that file or its
comments, and no migration advice. Its own kill (N-020): no stranger's star,
fork, watch or issue by 2026-11-12, or an official per-version reference
appears first.
